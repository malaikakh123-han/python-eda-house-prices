# Python Exploratory Data Analysis — House Prices

## Overview

This project performs Exploratory Data Analysis (EDA) on a messy house prices dataset using Python.

The analysis focuses on understanding the dataset, identifying data quality issues, exploring property prices, detecting outliers, analyzing categorical variables, and examining relationships between numerical features.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Dataset exploration and structure
- Data quality assessment
- Missing value analysis
- Duplicate detection
- Categorical data analysis
- Data cleaning and standardization
- Descriptive statistics
- Price distribution analysis
- Outlier detection using IQR
- Z-score outlier detection
- Data visualization
- Correlation analysis
- Multivariate analysis

## Key Findings

- Property prices are strongly right-skewed.
- The dataset contains inconsistent categorical values.
- Several potential price and area outliers were identified.
- Karachi has the largest number of property listings.
- Numerical variables show generally weak linear correlations with property price.

## Project File

`EDA_Assignment_01.ipynb`

The notebook contains the complete Python analysis, visualizations, interpretations, and recommendations.
